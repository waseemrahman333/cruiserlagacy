# Changelog

All notable changes to the Tailpine theme are documented here.

## [Unreleased] — 2026-09-24

### Added

* **`theme-variables.css` runtime design variables:** Added a new runtime
  stylesheet generated from Tailpine theme settings. It passes configured
  layout and color theme values from the theme settings into CSS custom
  properties.

* **Responsive container variables:** Added responsive
  `--t-container-padding-inline` variables generated from the configured
  layout settings, allowing container spacing to adapt across mobile, tablet,
  desktop, and wide desktop breakpoints.

* **Dynamic color theme variables:** Added runtime color variables for primary,
  secondary, tertiary, body, heading, surface, border, focus, shadow, success,
  warning, error, and info colors based on the selected Tailpine color theme.

* **Tailwind v4 theme mappings:** Added dynamic semantic Tailwind v4 theme
  tokens in `theme-tokens.css`, including `primary`, `primary-content`,
  `secondary`, `secondary-content`, `tertiary`, `tertiary-content`, `body`,
  `body-bg`, `heading`, `border`, `surface-100`, `surface-200`, `surface-300`,
  `focus`, `success`, `success-content`, `warning`, `warning-content`,
  `error`, `error-content`, and `info`.

* **Dynamic color theme integration:** Connected the Tailwind semantic tokens
  to the runtime variables generated by `theme-variables.css`. For example,
  the `primary` and `primary-content` Tailwind tokens use the values provided
  by `--t-primary` and `--t-on-primary`.

* **Theme-based color switching:** Added support for applying different color
  values through `html[data-theme="..."]`. When the active `data-theme` changes,
  the corresponding `--t-*` values change while the Tailwind semantic tokens
  continue to reference those runtime values.

  For example, a theme can define:

  ```css
  html[data-theme="custom"] {
    --t-primary: #A3E635;
    --t-on-primary: #1A2E05;
    --t-secondary: #365314;
    --t-on-secondary: #FFFFFF;
    --t-tertiary: #84CC16;
    --t-on-tertiary: #1A2E05;
    --t-body: #ECFCCB;
    --t-heading: #F7FEE7;
    --t-body-bg: #1A2E05;
    --t-surface-100: #1A2E05;
    --t-surface-200: #365314;
    --t-surface-300: #4D7C0F;
    --t-border: #4D7C0F;
    --t-focus-ring: #A3E635;
    --t-shadow: rgba(0, 0, 0, 0.4);
    --t-success: #86EFAC;
    --t-on-success: #052E16;
    --t-warning: #FCD34D;
    --t-on-warning: #451A03;
    --t-error: #FCA5A5;
    --t-on-error: #450A0A;
    --t-info: #7DD3FC;
    --t-on-info: #082F49;
  }
  ```

  These runtime values are then exposed through the semantic Tailwind tokens.
  For example, `primary` uses `--t-primary`, while `primary-content` uses
  `--t-on-primary`. This allows components to use semantic classes such as
  `bg-primary` and `text-primary-content` without directly referencing the
  runtime `--t-*` variables.

* **Dynamic font mappings:** Added Tailwind font tokens for Archivo, Avenir,
  Inter, Montserrat, and Poppins.

* **Wide container token:** Added the `8xl` container size to support the wide
  layout option.

* **Typography variables:** Added configurable typography variables for the
  selected body font, heading font, base font size, and responsive typography
  settings.

### Changed

* **CSS loading order:** Updated the Tailpine CSS library loading order so the
  base Tailpine CSS loads correctly in the page `<head>` before generated
  subtheme CSS.

* **Runtime theme stylesheet:** Added `theme-variables.css` to the Tailpine
  stylesheet library so runtime design variables are available to the
  frontend.

* **Container system:** Redesigned the container system to provide more
  flexible control over container width, layout, padding, and content
  container classes.

* **Tailwind subtheme support:** Updated the CSS setup so Tailwind CSS from the
  Tailpine base theme loads correctly in generated subthemes and utility
  classes are available to the subtheme.

* **Base and subtheme CSS order:** Ensured the Tailpine base theme CSS loads
  before generated subtheme CSS so subtheme styles can correctly override base
  styles.

### Fixed

* **Global Swiper loading:** Prevented the Swiper library from loading globally
  on every page, reducing unnecessary frontend asset loading.

* **Canvas page templates:** Fixed Drupal Canvas page template support in
  Tailpine and addressed the related subtheme compatibility issue.

* **Canvas PageRegion assertion:** Fixed the `PageRegion` validation/assertion
  issue encountered when using Drupal Canvas page templates.

* **Base Hero background:** Fixed the background issue in the Base Hero
  component.

* **CTA arrow icon:** Added the missing arrow icon and configurable CTA border
  options to the CTA component.

* **Card Wrapper background:** Fixed the Card Wrapper background color property
  and made the columns and text colors configurable through Canvas.

* **Card Style text colors:** Added dynamic text color options for Card Style
  One and Card Style Two.

* **Component Twig structure:** Refactored the component Twig template to
  support conditional wrappers, correct structural mismatches, and consistent
  vertical alignment based on the component schema.

* **Subtheme generation:** Fixed the Tailpine subtheme generation issue caused
  by Drupal core changes.

* **Theme setting variables in subthemes:** Fixed the base theme foundation and
  theme setting variables so they work correctly in generated subthemes.

* **`drush updb` compatibility:** Restored the required theme command
  functionality that was removed and could cause `drush updb` to fail on
  existing Tailpine sites.

* **`processNestedArray()` error:** Fixed the undefined `processNestedArray()`
  error in `drupak2026.theme` by using the updated Tailpine function.

* **Views wrapper:** Removed unnecessary styling and the extra wrapper `<div>`
  from `views-view-unformatted.html.twig`.

* **Hidden block labels:** Fixed block labels being displayed when the label is
  configured as Hidden.

* **Admin theme settings:** Fixed the `InvalidArgumentException` caused by the
  missing `tailpine_form_system_theme_settings_alter` implementation.

* **Search icon:** Fixed the broken search icon.

* **Hamburger menu:** Fixed the hamburger menu behavior.

* **Mobile logo:** Fixed the Tailpine logo display issue on mobile.

* **Active menu links:** Fixed the missing active class on menu links.

* **Color switcher:** Fixed the color switcher layout rendering outside its
  parent container.

### Improved

* **Header styles:** Improved the header style options and their region
  structure.

* **Footer styles:** Improved the footer style options and removed unnecessary
  footer regions from the starter kit.

* **Page layout:** Improved the `page.html.twig` layout structure.

* **Search form:** Redesigned the Tailpine search form.

* **Color scheme:** Improved color scheme configuration, placement, and theme
  setting behavior.

* **Hero Canvas controls:** Added dynamic Canvas configuration for Hero Wrapper
  and Hero Styles 1–4, including heading text and color values.

* **Admin theme:** Improved the Tailpine admin theme layout and design across
  Drupal administration pages.

* **Theme functions:** Added an `includes` directory and separated theme
  functions and preprocess functions from `tailpine.theme`.

* **Starterkit regions:** Updated the starterkit regions used when generating
  Tailpine subthemes.

* **Component testing:** Performed frontend and backend testing of Tailpine
  components and the existing site to identify compatibility and design issues.

* **Tailwind configuration:** Removed unsupported `daisyui_enable` configuration
  usage.

* **Create Account menu:** Added the Create Account menu configuration for
  Tailpine.
